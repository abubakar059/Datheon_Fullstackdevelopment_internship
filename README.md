# Datheon Full Stack Web Development Internship

This repository contains the projects I completed during my **Datheon Full Stack Web Development Internship**. Each task demonstrates my practical skills in frontend development, JavaScript programming, responsive UI design, and API integration.

## Projects

### Task 01 - Personal Portfolio

A responsive personal portfolio website showcasing my profile, skills, projects, and contact information.

**Technologies:**
- HTML5
- CSS3
- Vanilla JavaScript

**Project folder:** `Task-01-Portfolio/`

### Task 02 - Daymark Productivity App

A productivity and task management application that allows users to create, manage, categorize, update, and delete tasks. It includes due dates, task status filters, search functionality, drag-and-drop reordering, and browser localStorage for persistent data.

**Technologies:**
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Browser localStorage API

**Project folder:** `Task-02-Productivity-App/`

### Task 03 - Atmos Weather Application

A responsive weather telemetry application that allows users to search for cities worldwide and view current weather conditions, temperature, humidity, wind speed, atmospheric pressure, precipitation, and a five-day forecast. It also includes live city suggestions, Celsius/Fahrenheit conversion, loading indicators, and error handling.

**Technologies:**
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Fetch API
- Open-Meteo Geocoding and Weather APIs
- Async/Await

**Project folder:** `Task-03-Weather-App/`

## How to Run the Projects

1. Clone or download this repository.
2. Open the desired task folder in Visual Studio Code.
3. Open `index.html` in your browser or run it using the VS Code Live Server extension.
4. Refer to the individual project README files for specific setup instructions.

**Note:** The Atmos Weather Application requires an active internet connection to retrieve live weather data.
