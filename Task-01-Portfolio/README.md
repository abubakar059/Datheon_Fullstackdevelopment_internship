# Muhammad Abubakar — Portfolio

A personal portfolio website showcasing my web development projects, skills, and background.

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Responsive website design
- Dark and light theme toggle
- Mobile navigation
- Interactive project previews
- About, skills, and contact sections

## Featured Projects
- JCM Two
- Kalsoom Beauty
- MCR Gray
- Lepro Wellness Center

## Run Locally
1. Open the `Task-01-Portfolio` folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
